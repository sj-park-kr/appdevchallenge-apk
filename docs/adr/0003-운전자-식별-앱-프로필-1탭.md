# 0003. 운전자는 앱 자체 직원 목록에서 P단 1탭으로 고른다

- 상태: 채택 · 날짜: 2026-10-23

## 맥락
운행기록부와 과태료 대응 모두 "누가 운전했나"가 필요하다. Pleos SDK에는 사용자 프로필·블루투스 연결 기기 API가 없다. 음성(STT)은 준비 중이다. 본인 확인(PIN 등)을 넣으면 탭 수가 늘고, 실무에서는 다른 사람이 대신 골라 주는 경우도 있다.

## 결정
- 앱에 직원 목록을 두고, **시동 후 P단에서 1탭**으로 운전자를 고른다. 지난 운전자를 기본 선택한다.
- **본인 확인은 하지 않는다.** 대리 선택을 허용한다.
- 고르지 않고 출발하면 "미지정"으로 기록하고, 도착 P단에서 다시 묻는다.
- 시트 위치로 추천(P2). 블루투스·Pleos 프로필·음성은 로드맵.

## 결과
- 운전자 칸은 "사람 입력"이므로 신뢰 수준이 자동값보다 낮다. 화면·엑셀에서 자동값과 구분해 표시한다.
- 나중에 바꾸면 수정 이력이 남는다([0008](0008-append-only-이벤트와-수정-이력.md)).
- "미지정 비율"을 품질 지표로 본다.
