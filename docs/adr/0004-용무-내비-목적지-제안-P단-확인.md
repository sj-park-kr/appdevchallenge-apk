# 0004. 용무는 내비 목적지·즐겨찾기로 제안하고 도착 P단에서 1탭 확인한다

- 상태: 채택 · 날짜: 2026-10-23

## 맥락
양식의 업무용 사용거리는 용무(출퇴근/일반 업무)에 달려 있다. 감사 사례에서 용무는 '기타'로 뭉개지기 쉬운 칸이었다. 주행 중 입력은 안전 가이드상 받을 수 없다.

## 결정
- 제안 규칙(위에서부터): 즐겨찾기 근처 도착 = `업무: {이름} 방문` → 회사 위치 + 출퇴근 시간대 = `출퇴근` → 내비 목적지 = `업무: {목적지}?` → 그 외 = `업무: {주소}?`
- **도착 후 P단**에서 1탭 확인. 놓치면 다음 시동 때 먼저 묻는다. 그래도 비면 관리자가 채운다.
- 집 주소는 저장하지 않는다.

## 결과
- 내비 즐겨찾기를 거래처 목록으로 쓰게 되어 따로 거래처 등록 화면이 필요 없다.
- 확인하지 않은 운행은 엑셀에서 업무 거리 0(보수적)으로 계산된다 → 확인할 동기가 생긴다.
- 반경(200m)·시간대 값은 가정이며 설정으로 바꿀 수 있다. 즐겨찾기 값 형식은 에뮬레이터 확인 필요.
