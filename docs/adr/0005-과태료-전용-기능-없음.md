# 0005. 과태료 전용 기능은 만들지 않고 기록 조회로 대신한다

- 상태: 채택 · 날짜: 2026-10-23

## 맥락
무인단속 과태료는 차 소유자(회사)에게 오므로 회사가 운전자를 찾아야 한다. 하지만 관리자가 이걸로 크게 불편하다는 원문 근거는 찾지 못했다. 고지서 입력·매칭 화면은 범위를 키운다.

## 결정
과태료 화면을 따로 만들지 않는다. 기록 목록을 **날짜·시간대·운전자로 거르는 기능**으로 "그 시각 누가 탔나"에 답한다.

## 결과
- 같은 필터가 세무 검토("이날 어디 갔나")에도 쓰인다.
- 시간대 필터는 "그 시간에 걸친 운행"을 보여야 한다(시작·끝이 범위 밖이어도 포함).
- 고지서 자동 매칭은 로드맵.
