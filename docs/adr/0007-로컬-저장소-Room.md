# 0007. 기록은 차 안의 SQLite(Room)에 저장한다

- 상태: 채택 · 날짜: 2026-10-23

## 맥락
기록은 네트워크와 상관없이 남아야 한다(지하주차장, 통신 미가입). 서버 계정·동기화는 MVP 범위 밖이다. 저장량은 5년에 이벤트 수십만 건 이하(가정)다.

## 결정
- 차 안의 **Room(SQLite)** 하나에 저장한다. 서버 동기화 없음.
- 앱 백업·복원(`allowBackup`)은 끈다 — 밖에서 편집한 DB가 복원되는 길을 막는다.
- 빌드 종류별 DB 파일 분리(`truelog.db` / `truelog-demo.db`).

## 결과
- 오프라인에서 항상 동작한다.
- **앱 삭제·초기화 시 기록이 사라진다.** 재설치 후 첫 이벤트를 "기록 시작점"으로 남기고, 이전 구간은 공백으로 드러낸다. 서버 백업은 로드맵.
- SQLite 트리거로 UPDATE/DELETE를 막을 수 있다([0008](0008-append-only-이벤트와-수정-이력.md)).
