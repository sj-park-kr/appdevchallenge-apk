# 0010. 내보내기는 xlsx를 직접 만들어 짧은 만료 링크로 올리고 QR로 받는다

- 상태: 채택 · 날짜: 2026-10-23

## 맥락
담당자는 월말에 국세청 양식 엑셀을 세무 대리인에게 보내야 한다. 차 화면에는 메일·파일 공유 수단이 마땅치 않고, 폰과 차를 직접 잇는 SDK도 없다. 파일에는 직원 이름과 위치가 들어 있다.

## 결정
- **xlsx는 직접 작성**한다(`java.util.zip` + XML, 시트 5개). Apache POI는 Android에서 무겁고 호환 문제가 있어 쓰지 않는다.
- 생성한 파일을 HTTPS로 **최소 서버**에 올리고, 서버는 임의 토큰(128비트) 링크를 돌려준다. 앱은 링크를 QR로 보여 준다.
- 링크는 **1회 다운로드 또는 10분(가정) 뒤 삭제**. 서버는 계정·DB 없이 파일 임시 보관만 한다(호스팅은 서버리스 함수 + 객체 저장소 등, 구현 때 결정).
- 서버가 안 될 때(시연 백업)는 외부 저장소에 쓰고 `adb pull`.

## 결과
- 차에서 폰으로 한 번 찍어 바로 받는다. 앱에 로그인이 필요 없다.
- 서버 운영이 필요하다(작지만 0은 아님). 만료·1회 제한으로 노출 시간을 줄인다.
- 서버가 평문 파일을 잠깐 갖는다. 링크 조각(`#key`)에 키를 넣는 종단 암호화는 복호화용 웹 페이지가 필요해 로드맵.
- xlsx 직접 작성은 서식(병합·테두리)을 최소로만 지원한다. 양식 칸은 고시 원문과 대조 필요.
