# 0012. Android 사용자별 데이터 분리는 "기록 공백"으로 드러내고, 법인 차는 사용자 하나로 쓰도록 안내한다

- 상태: 채택 · 날짜: 2026-10-23

## 맥락
AAOS는 여러 Android 사용자(프로필)를 지원하고, 앱 데이터는 사용자별로 분리된다. 직원마다 다른 Android 사용자로 로그인하면 기록이 사용자별 DB로 흩어지고, 백그라운드 서비스도 현재 사용자에서만 돈다. 모든 사용자를 아우르는 저장(시스템 앱 권한)은 서드파티 앱으로는 어렵다.

## 결정
- MVP는 **차 한 대 = Android 사용자 하나**를 전제로 한다(설정 화면·README에 안내).
- 다른 사용자로 운전한 구간은 계기판 거리 차이로 **기록 공백**에 나타난다([0011](0011-운행-경계-시동-기준.md)).
- 여러 사용자 기록 합치기는 서버 동기화가 생길 때 로드맵으로.

## 결과
- 추가 구현 없이 공백 규칙으로 문제가 드러난다.
- 직원별 Android 사용자를 쓰는 회사에서는 공백이 많아진다 → 공백 안내 문구에 "다른 사용자 프로필로 운전했을 수 있음"을 넣는다.
- Pleos 에뮬레이터·실차의 기본 사용자 구성(헤드리스 시스템 사용자 여부)은 확인 필요.
